# CrAIshPad

CrAIshPad is planned as a native companion app for people who want a familiar conversation, user-controlled persona, and persistent memories across sessions.

This public repository is the handoff for a **new native app**. It intentionally does not contain the retired web prototype or Leo’s private app source. The app code still needs to be built in a dedicated Replit project: this workspace already has its one allowed Expo mobile artifact.

## Start here

1. Read [`AGENTS.md`](AGENTS.md) for product requirements and boundaries.
2. Read [`docs/BUILD_STATUS.md`](docs/BUILD_STATUS.md) for API availability and blocked integrations.
3. Start a fresh Replit project from this repository, then scaffold the Expo app there.

## Current repository contents

- `assets/craishpad-native-icon.png` — generated app icon concept.
- `AGENTS.md` — product scope and implementation instructions for the next coding agent.
- `docs/BUILD_STATUS.md` — current status and prerequisites.

No user conversations, private prompts, API keys, or app data belong in this repository.
